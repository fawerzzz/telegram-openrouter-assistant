
# Telegram OpenRouter Assistant

Telegram-бот, который позволяет взаимодействовать с языковыми моделями через OpenRouter API.

## Стек

- Python
- aiogram
- OpenRouter API
- PostgreSQL
- Docker и Docker Compose
- Jenkins

## Возможности

- **Общение с языковыми моделями** — обработка сообщений через OpenRouter API.
- **Напоминания** — создание и управление напоминаниями с хранением данных в PostgreSQL.
- **Работа в групповых чатах** — возможность обращаться к боту через упоминание, например `@userbot привет, как дела?`.
- **Работа в топиках** — поддержка взаимодействия в отдельных темах Telegram-групп.


## CI/CD

Для автоматизации сборки и развёртывания используется Jenkins.

Pipeline выполняет следующие этапы:

1. **Checkout** — получение исходного кода из GitHub.
2. **Validation** — проверка Python-кода и конфигурации Docker Compose.
3. **Build** — сборка Docker-образа приложения.
4. **Deploy** — запуск или обновление приложения на сервере с помощью Docker Compose.

Секретные переменные окружения хранятся в Jenkins Credentials и не добавляются в репозиторий.

## Запуск

Для локального запуска необходимы Docker и Docker Compose.

1. Клонировать репозиторий.
2. Создать `.env` на основе `.env.example`.
3. Заполнить необходимые переменные окружения.
4. Запустить приложение:

```bash
docker compose up -d --build
```

Для остановки:

```bash
docker compose down
```
